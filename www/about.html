关于这个协议栈

从数据链路到 HTTP 的最小闭环

首页 关于协议栈 请求示例

实现范围

  • 数据链路层：通过 npcap 捕获和发送以太网帧。
  • 网络层：IPv4 头部封装、校验和计算、按协议号分发。
  • 传输层：TCP 三次握手、挥手、基本状态机和简单滑动窗口。
  • 应用层：HTTP/1.1 简化实现，支持静态文件 GET 请求。

你可以做的实验

  1. 用浏览器多次刷新不同页面，观察 TCP 连接数和状态变化。
  2. 在代码中增加日志，追踪一次 HTTP 请求从网卡到应用层的完整路径。
  3. 尝试加入新的 MIME 类型或增加一个简单的 JSON API。

你可以随时根据需要扩展这个协议栈，例如增加更多应用协议或完善 TCP 细节。
