欢迎

你现在看到的页面，是通过你自己实现的 TCP/IP 协议栈 + HTTP 服务器直接返回给浏览器的静态资源。

建议多开几个标签页，同时访问不同页面来观察连接建立、数据收发和关闭的状态变化。

支持静态文件

HTML、CSS、JS、图片等静态资源都可以通过简单的 GET 请求访问。

最小可用 HTTP

实现了基础的请求行解析、状态码处理，以及按扩展名返回合适的 Content-Type。

方便调试

配合命令行中的日志输出，可以从浏览器到协议栈完整观察一次 HTTP 请求的生命周期。
